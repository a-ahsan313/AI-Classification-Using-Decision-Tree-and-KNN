# AI-Classification-Using-Decision-Tree-and-KNN
A Machine Learning classification project using Decision Tree and K-Nearest Neighbors (KNN) on the Iris Dataset.

This project was developed as part of the DecodeLabs Artificial Intelligence Internship Program.

---

# Project Objective

The objective of this project is to:
- Understand supervised learning
- Load and analyze a dataset
- Split data into training and testing sets
- Train a machine learning model
- Predict outputs using AI
- Evaluate model accuracy

---

# Technologies Used

- Python
- Pandas
- Scikit-Learn
- Machine Learning
- Decision Tree Classifier
- K-Nearest Neighbors (KNN)

---

# Dataset Used

Iris Flower Dataset

The dataset contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

Target Classes:
- Setosa
- Versicolor
- Virginica

---

# Machine Learning Workflow

1. Load Dataset
2. Prepare Features and Labels
3. Split Dataset
4. Train AI Model
5. Test Model
6. Predict Results
7. Evaluate Accuracy

---

# Algorithm Used

## 1. Decision Tree Classifier
Decision Tree is a supervised machine learning algorithm used for classification and prediction tasks.

## 2. K-Nearest Neighbors (KNN)
A simple supervised learning algorithm that classifies data based on the nearest neighboring data points.
